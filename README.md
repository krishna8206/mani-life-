# Mani Lifestyle

Production repository for **Mani Lifestyle** — Certified Cosmetics Manufacturer based in Ahmedabad, Gujarat, India.

## Architecture

This repository is structured as a modern workspace:

- [`frontend/`](./frontend) — Next.js 16 (App Router + Turbopack + Tailwind CSS v4) storefront application.
- *(Future workspace)* `admin/` — Admin management dashboard.

## Quick Start

From the root directory:

```bash
# Install dependencies
npm install

# Run the storefront development server
npm run dev

# Run production build
npm run build

# Run linting
npm run lint
```

Or navigate directly to the frontend package:

```bash
cd frontend
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
